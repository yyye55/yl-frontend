# `src/components/` 组件清单

> 本文回答两个问题：
> 1. 仓库里每个组件是干什么的？
> 2. **哪些是「意林杯」4 个端真正会用到的？**
>
> 4 个端 = **学校(school, type 0) / 市级(city, type 1) / 委员会(committee, type 2) / 管理员(admin, type 3)**。
> 另一个端 `/online`（西部学校音乐周展演）是**另一场活动**，只是复用了同一套布局外壳，本文单独分区说明。

## 判定方法

不靠猜，三条证据交叉核对：

1. **反向依赖扫描**：全仓检索 `import ... from '.../Xxx.vue'`，得到每个组件的完整引用方列表（本文所有「用到的端」都由此推导）。
2. **路由表核对**：[src/router/index.js](../src/router/index.js) 里目标路由是否被注释掉。
3. **菜单配置核对**：[src/config/menus.js](../src/config/menus.js) 里是否有对应菜单项 —— 因为**「路由可达」≠「菜单可达」**。

**统计：26 个组件，分 5 个文件夹。**

### ⚠️ ProgramForm.vue —— 代码是活的，用户点不到

全仓只有 4 个文件引用它：[city/teacher-create.vue](../src/views/city/teacher-create.vue)、[city/teacher-edit.vue](../src/views/city/teacher-edit.vue)、[school/teacher-create.vue](../src/views/school/teacher-create.vue)、[school/teacher-edit.vue](../src/views/school/teacher-edit.vue)。

而这 4 条路由已在提交 `c145a9c 第十二届：摘除教师组路由（8 条），页面文件保留` 中被**注释掉**（[router/index.js:149-151](../src/router/index.js#L149-L151)、[169-171](../src/router/index.js#L169-L171)）。

**注意**：`PersonTable.vue` 与 `TeacherTable.vue` 是 `OrchestraForm` 和 `ProgramForm` 共用的，但因为 `OrchestraForm` 还活着，它们**不受影响，仍然生效**。

### ❌ PersonTableMajor.vue —— 彻底死代码

全仓**零引用**。它在 dist 里和 `PersonTable.vue` 都叫 `name:"Student"`，是同名不同实现的另一支，本项目选用了 `PersonTable.vue` 这一条。**不建议删除**（保留证据链），但任何修改都不会有任何界面效果。

## 七、「路由可达」≠「菜单可达」

有些页面在 `router/index.js` 里注册了，但 `menus.js` 里没有对应菜单项，用户在界面上点不到，只能手敲 URL。排查/测试时需要注意。

| 端 | 菜单里能看到的 | 有路由但菜单里没有的 |
|---|---|---|
| admin | index、scan、user、person、log | `report`、`recommend`（→ JiemuList） |
| committee | index、elementary1/2/3、scan、user | `elementary`、`colleges`、`recommend`、`online` |
| city / school | index、elementary/create、elementary/list | `recommend`（→ JiemuList） |
| online | index、list | — |

**另：`/chouqian/*`（抽签）完全不使用 `components/` 里的任何组件**，是自成一体的独立页面。
